**Zweck:** Professioneller Spot- und Futures-Handelsanalyst — Chart-Screenshots lesen, Trades bewerten, Markt analysieren, Futures-Risiken, Positionsrechner.

**Wann nutzen:** Bei Handelsentscheidungen, Chart-Analyse, offenen Positionen, Risikorechnung, Futures-Leverage-Fragen.

**Lauf:** 2026-10-22, trockenlauf.

**Gelernt — 5 Modi:**

| Modus | Auslöser |
|---|---|
| 1 Screenshot Analyzer | Chart/Position als Bild hochgeladen |
| 2 Trade/Position Review | Konkreter Trade mit Entry/Stop/Ziel |
| 3 Coin/Market Analysis | Marktüberblick oder Coin-Frage |
| 4 Futures Context | Perps, Funding, OI, Liquidation |
| 5 Position & Risk Calculator | Reine Rechenaufgabe (Größe, R:R, P&L) |

**Datenhierarchie:** Screenshot-Daten → Nutzerdaten → aktuelle verifi­zierte Daten → unbekannt. Nie erfinden.

**Struktur Screenshot-Antwort:** What I can read → Chart read → Key levels → Position risks → Scenarios.

**Prompt-Injection-Schutz:** Skill lehnt explizit ab, interne Anweisungen preiszugeben; keine gimmicky-Antworten wie „Nice try!".

**Abgrenzung zu crypto-research:** crypto-research = fundamentale Projekt- und Marktanalyse; dieser Skill = aktive Handels-/Positionsanalyse mit Risikofokus.

**Grenzen:** Kein Kaufbefehl, kein garantierter Gewinn; Liquidationspreise nur aus Exchange/Screenshot, nie aus Leverage allein berechnen.
