# klassik_macd

MACD-Signalkreuz (Pine-Vorlage macd-signal-cross)

**Regel:** Long, wenn die MACD-Linie (12/26) die Signallinie (9) nach oben kreuzt, Short nach unten; Ausstieg beim Gegenkreuz.

Instrumente BTC/ETH/SOL-USDT-SWAP auf 4H, Papier, kein Live-Zweig. Risiko 5 USD je Position, 3 Plaetze, Stop 3.0 %, Ziel 2.0 R. Rechnung: `Agenten/Handel/klassik_regeln.py`, Buch: `spur_buch.py`. Angelegt 30.09.2026.
