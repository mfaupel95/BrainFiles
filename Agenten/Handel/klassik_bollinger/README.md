# klassik_bollinger

Bollinger-Ausbruch (Pine-Vorlage bollinger-breakout)

**Regel:** Long, wenn der Schluss das obere Band (20, 2) nach oben durchbricht, Short am unteren Band; Ausstieg beim Gegensignal.

Instrumente BTC/ETH/SOL-USDT-SWAP auf 4H, Papier, kein Live-Zweig. Risiko 5 USD je Position, 3 Plaetze, Stop 4.0 %, Ziel 2.0 R. Rechnung: `Agenten/Handel/klassik_regeln.py`, Buch: `spur_buch.py`. Angelegt 30.09.2026.
