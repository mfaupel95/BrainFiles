# klassik_rsi

RSI-Rueckkehr (Pine-Vorlage rsi-mean-reversion)

**Regel:** Long, wenn RSI(14) von unten ueber 30 kreuzt, Short, wenn er von oben unter 70 kreuzt; Ausstieg Long bei RSI 55, Short bei 45.

Instrumente BTC/ETH/SOL-USDT-SWAP auf 4H, Papier, kein Live-Zweig. Risiko 5 USD je Position, 3 Plaetze, Stop 4.0 %, Ziel 1.0 R. Rechnung: `Agenten/Handel/klassik_regeln.py`, Buch: `spur_buch.py`. Angelegt 30.09.2026.
