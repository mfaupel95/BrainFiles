# Versionsverwaltung von BrainFiles - WHITELIST
#
# Dieses Repository sichert NICHT den Vault. Das tun sichern.ps1 (G:) und
# sichern-zweitkopie.ps1 (O:). Es schliesst die eine Luecke, die alle drei
# Kopien teilen: Sie halten nur den JETZIGEN Stand. Ein Fehler, der laenger als
# bis 20:00 unbemerkt bleibt, steht danach in allen dreien. Git haelt die
# Vorgeschichte - deshalb hier nur, was sich von Hand aendert und was weh taete,
# wenn es still kaputtginge.
#
# Bewusst eine Whitelist: erst alles ignorieren, dann einzeln freigeben. Eine
# Blacklist waere die falsche Richtung - sie nimmt jede neue Datei ungefragt
# auf, und genau so landen 45 GB Medien oder ein Zugangsschluessel im Verlauf.
#
# Seit dem 30.08.2026 liegt die Wurzel eine Ebene hoeher: nicht mehr in
# MaxHirn/, sondern in BrainFiles/. Jede Freigabe unten traegt deshalb den
# Ordner im Pfad. Die vier Ordner haben je eine Aufgabe - MaxHirn/ Wissen,
# Modelle/ Gewichte, Agenten/ was laeuft, Werkstatt/ gemeinsame Arbeit.
